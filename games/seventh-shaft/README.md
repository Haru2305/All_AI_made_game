# 第七坑 — 深層採掘局

ブラウザだけで動く、日本語のインクリメンタルゲームです。地殻を掘り進めながら、設備投資・熱圧・契約・長期の免許更新を管理します。外部ライブラリやサーバーは使いません。

## 起動

`index.html` をブラウザで開きます。ローカル HTTP サーバーを使う場合は、次のコマンドをプロジェクトのディレクトリで実行してください。

```sh
python3 -m http.server 8000
```

`http://localhost:8000` にアクセスすると遊べます。

## 操業の流れ

- 設備が「抽出量」を自動で増やします。抽出量は売却されて操業資金になり、区画ノルマにも加算されます。
- 設備を増やすと採掘速度が上がります。同じ設備を 10 / 25 / 50 / 100 基まで増やすたび、設備出力が倍増します。
- 手動打撃は少量の追加抽出を生みます。打撃の反動と設備の熱圧を見ながら使います。
- 熱圧が高いと採掘効率と設備健全度が下がります。自然冷却を待つか、強制排気弁を使ってください。
- 区画突破と契約履行で記録片を集め、技術台帳を実装します。
- 第 8 区以降で操業免許を更新できます。設備・現金・現在区画は失いますが、特記印、研究、実績と契約履歴は引き継ぎます。
- 記録はブラウザ内に自動保存されます。設定画面から JSON の書き出しと読み込みができます。閉鎖中の操業は最大 2 時間分を反映します（技術と免許特記で延長）。

## ファイル

- `index.html` — ゲーム画面
- `styles.css` — レイアウト、演出、レスポンシブ表示
- `game.js` — 操業、進行、保存、契約、研究、免許更新

ブラウザの保存領域を消去するとゲーム記録も削除されます。端末を移すときは JSON を書き出してください。
