# 灰線航路 — ASHLINE ATLAS

**ジャンル:** オープンワールド・インクリメンタル / 探査・産業運営  
**形式:** ビルド不要のブラウザーゲーム（HTML / CSS / JavaScript）  
**起動:** \`index.html\` をブラウザーで開く

## 作品概要

灰嵐の時代。外縁大陸には旧世界の産業設備が埋まり、いくつもの勢力がわずかな燃料を奪い合っている。プレイヤーは装甲探査車「灰線号」を操り、地図の空白へ自分の航路を刻む。

## 遊びの柱

- **自由な大陸踏査:** 六角地図を走査し、見つけた地形を選んで航行。道順も拠点の場所も自分で決める。
- **積み上がる産業網:** 鉄屑・電力・測量データを生む前哨基地を、地形ごとの産出差を見て建設・増設する。
- **遠征の危険と手当て:** 汚染域では車体が削られる。電力と船体を見ながら、廃墟の回収を続けるか退くかを判断する。
- **選べる技術と車両改造:** 走査、航続、産出、修理、回収の系統を開き、広い大陸を渡るための運用を整える。
- **勢力間の取引:** 四つの勢力の依頼を達成して評判と「刻印」を獲得。任務の得意分野を選び、恒久的な改良へつなげる。
- **再編と記録の継承:** 一定の踏査成果を持って管轄権を返上すると、前哨網を手放す代わりに航海誌・発見地・刻印を残して新しい遠征を始める。

## 操作

- 地図上で既知の六角タイルを選び、詳細カードの「航路を設定」から移動。
- 「広域走査」で現在地周辺の未踏地を発見。
- 旧施設を回収し、資源産出タイルに前哨基地を設置。
- 航海誌のバックアップ機能でセーブをJSONに書き出し・読み込み。

セーブはブラウザーの \`localStorage\` に保存されます。ネット接続は不要です（フォントを除く）。
