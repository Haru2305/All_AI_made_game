# AI全任せゲーム工房

作るたびに、ブラウザーで遊べるゲームを \`games/\` に追加しています。最新版はオープンワールド型の踏査インクリメンタル **灰線航路 — ASHLINE ATLAS** です。

## Games

| タイトル | 内容 | 起動 |
| --- | --- | --- |
| [灰線航路 — ASHLINE ATLAS](games/ashline-atlas/) | 灰に覆われた大陸を自由に踏査し、資源前哨網と航路を築くオープンワールド・インクリメンタル。 | [ゲームを開く](games/ashline-atlas/index.html) |
| [第七坑 — 深層採掘局](games/seventh-shaft/) | 深層採掘と設備投資を積み上げるダーク・インクリメンタル。 | [ゲームを開く](games/seventh-shaft/index.html) |

## 灰線航路を遊ぶ

ブラウザーで \`games/ashline-atlas/index.html\` を開いてください。保存はブラウザー内に行われます。別の端末へ移す場合は、ゲーム内の「航海誌・データ保管」からJSONをバックアップできます。

各ゲームの仕様と操作は、それぞれのフォルダー内のREADMEに記載しています。
